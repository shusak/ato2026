# All Things Open 2026 - Raleigh, North Carolina

## Supply Chain Security in the Age of the AI Hacker

### Steve Husak

The rapid emergence of frontier AI models, exemplified by Anthropic’s Claude Mythos, has fundamentally altered cybersecurity economics by collapsing zero-day vulnerability discovery and exploit generation from months to seconds. This threat is particularly acute within the open source software (OSS) ecosystem, where unmaintained libraries and overworked maintainers present prime targets for automated offensive AI engines.

For large enterprises, defending against machine-speed exploitation requires moving beyond reactive patching. This talk presents a dual-track strategy: hardening immediate ingestion pipelines through pragmatic controls like artifact cool-down windows and AI-driven malware scanning, while establishing active upstream stewardship to support vulnerable OSS maintainers. Attendees will gain actionable blueprints for isolating abandonware, mitigating dependency risk, and building a sustainable defense-in-depth model for modern software supply chains.
